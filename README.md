### 📈 CryptoPredict

Proyecto de análisis y predicción del mercado de criptomonedas mediante pipelines de datos y modelos de Machine Learning.

Incluye:

- ETL automatizado
- Data Lake en Parquet
- Ingeniería de características
- Entrenamiento y evaluación de modelos
- API para servir predicciones

**Tecnologías**

`Python` `XGBoost` `Pandas` `Scikit-Learn` `FastAPI`

`Python` `TensorFlow` `Keras`
